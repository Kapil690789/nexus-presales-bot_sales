Riverview Clinic — patient companion

A HIPAA-aware companion for visit reminders and follow-up — scoped to the pilot cohort, not a hospital-wide platform.

iOS Android React Native Node.js
Challenge

Patients missed appointments. Reminders were generic SMS and not tied to visit type or the clinic’s existing systems.

Approach

React Native + Node companion with auth, visit reminders, and data handling appropriate for a HIPAA-aware pilot.

Outcome

HIPAA-aware companion app; no-show rate down 18% in the pilot cohort.
